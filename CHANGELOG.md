#  Changelog

> [!NOTE]
> Mark is in pre-release development. Semantic versioning does not apply before version 1.0.0, so version numbers reflect development stages rather than stable public releases.

## Mark 0.3.0 (unreleased)

- Import `.docx` files
- Automaticallty insert the matching closing brackets or wrap selected text in typed brackets
- Highlight text

## Mark 0.2.0

- Import and export plain text files
- Rewritten parsing and formatting engines
- Editor view and speaker formatting settings
- About window

## Mark 0.1.0

- Save documents in `.mark` format
- Store document metadata inside the file
- Implement parsing and text formatting
- Parse speakers and add speaker roles
- Lock document editing
